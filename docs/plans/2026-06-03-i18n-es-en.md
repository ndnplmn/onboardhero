# i18n EN/ES Toggle Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a language toggle (EN/ES) to the sidebar so every string in the app can be switched to Spanish instantly with no page reload.

**Architecture:** Custom React Context (`LanguageProvider`) with flat-nested dictionaries (`en.ts` / `es.ts`). A `useT()` hook returns a `t(key)` resolver. Preference is persisted in `localStorage`. The toggle button lives in the Sidebar.

**Tech Stack:** React 19 Context API, Next.js 16 App Router, TypeScript, localStorage.
